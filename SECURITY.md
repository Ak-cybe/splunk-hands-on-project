# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | ✅ Yes             |

## ⚠️ Important Disclaimer

This repository contains **simulated log data** and **sample attack patterns** for educational purposes only. No real credentials, API keys, or sensitive data are included.

## Reporting a Vulnerability

If you discover a security issue (e.g., accidentally committed credentials, exposed API keys):

1. **Do NOT** open a public issue
2. Contact: Open a private security advisory on GitHub
3. Expected response time: Within 48 hours

## Data Safety

- All IP addresses in sample data are from reserved/documentation ranges or randomly generated
- No real AWS credentials are included in the GuardDuty project
- All email addresses in SMTP logs are fictional
- MAC addresses in DHCP logs are randomly generated

---

**This project is designed for learning. Always practice security responsibly.** 🛡️
