# Contributing to Splunk SIEM — SOC Analyst Lab

Thank you for your interest in contributing to this project! 🎉

## 🤝 How to Contribute

### 🐛 Found a Bug?
1. Check if the issue already exists in [Issues](https://github.com/Ak-cybe/splunk-hands-on-project/issues)
2. If not, open a new issue with:
   - Clear title describing the problem
   - Steps to reproduce
   - Expected vs actual behavior

### 💡 Have an Idea?
- Open a [Feature Request](https://github.com/Ak-cybe/splunk-hands-on-project/issues/new) with:
  - What dashboard/analysis you'd like added
  - Why it would benefit SOC analysts
  - Any reference materials

### 🔧 Want to Submit Code?

1. **Fork** this repository
2. **Create** a feature branch: `git checkout -b feature/new-dashboard`
3. **Follow** the existing guide structure:
   - Typing SVG header + badges
   - Step-by-step tasks with SPL queries
   - SOC Analyst Tips in blockquotes
   - Complete XML reference
4. **Commit** with descriptive messages: `feat: add Windows Event Log dashboard`
5. **Push** and open a Pull Request

## 📋 Style Guide

- Use **Markdown** with consistent formatting
- Include **SPL queries** in fenced code blocks with `spl` language tag
- Add **SOC Analyst Tips** as blockquotes with 🔍 emoji
- Every dashboard needs: Single Value stats → Charts → Investigation Table → Geo Map
- Data files should be JSON, placed in `data/`
- XML dashboards go in `xml/`

## ⭐ Other Ways to Help
